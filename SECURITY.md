# Security policy

## Supported versions

Only the latest published version of `@plq/array-functions` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use
[GitHub private vulnerability reporting](https://github.com/Akurganow/array-functions/security/advisories/new)
instead, or email the maintainer at the address listed in `package.json`.

You will get an acknowledgement within a few days. Once a fix is available it is released as a patch version and the
advisory is published.
